# Customer-Data-Analysis-PowerBI-Dashboard
Power BI dashboard analyzing customer shopping behavior, revenue, age groups, gender distribution, and payment methods.
Here's a professional README.md tailored Customer Data Analysis Power BI Dashboard project.


Overview

The Customer Data Analysis Dashboard is an interactive Power BI solution developed to analyze customer shopping behavior across multiple shopping malls in Istanbul between 2021 and 2023.

This dashboard provides insights into customer demographics, purchasing patterns, revenue generation, product categories, payment methods, and shopping mall performance. The goal is to support data-driven decision-making through effective visual analytics.

Project Objectives

The dashboard addresses the following business questions:

How is the shopping distribution according to gender?
Which gender did we sell more products to?
Which gender generated more revenue?
What is the distribution of purchase categories?
How is the shopping distribution according to age?
Which age category did we sell more products to?
Which age category generated more revenue?
How do purchase categories vary across age groups?
Does the payment method have a relationship with other variables?
How is the distribution of payment methods?
Derive business insights and recommendations using Power BI visualizations.
Dataset Description

The dataset contains shopping transactions collected from 10 different shopping malls in Istanbul between 2021 and 2023.

Calculated Column
Age Group
Age Group =
SWITCH(
    TRUE(),
    [age] <= 20, "0-20",
    [age] <= 30, "21-30",
    [age] <= 40, "31-40",
    [age] <= 50, "41-50",
    [age] <= 60, "51-60",
    "61+"
)

DAX Measures
Total Revenue
Total Revenue =
SUMX(
    customer_data_segmentation,
    customer_data_segmentation[quantity] *
    customer_data_segmentation[price]
)

Total Quantity
Total Quantity =
SUM(customer_data_segmentation[quantity])

Total Transactions
Total Transactions =
DISTINCTCOUNT(customer_data_segmentation[invoice_no])

Average Order Value
Average Order Value =
DIVIDE(
    [Total Revenue],
    [Total Transactions]
)
